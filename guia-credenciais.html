Esta seção agrupa as notas de Cracking, Dump, Hashcat e Zip Passwords. Antes de executar qualquer ferramenta, identifique o formato do material, a permissão de uso e o objetivo do teste.

FIELD NOTE

01 / Hashcat e padrões conhecidos

Quando você já tem uma parte da senha e sua hash, pode testar o restante com uma máscara. Nas notas, o exemplo usa MD5 e quatro caracteres desconhecidos. Use hashes de laboratório, nunca de terceiros.

hashcat -a 3 -m 0 HASH_MD5 UHI75GHI?a?a?a?a

-a 3 seleciona ataque de máscara; -m 0 indica MD5. A máscara ?a representa o conjunto amplo de caracteres do Hashcat. Para gerar candidatas com regra:

hashcat --stdout pass.txt -r /usr/share/hashcat/rules/best64.rule > passwords.txt

O objetivo defensivo é avaliar se segredos previsíveis resistem às políticas e ao armazenamento escolhidos. MD5 puro não é apropriado para armazenar senhas.

FIELD NOTE

02 / Arquivos ZIP protegidos

As notas usam fcrackzip com uma wordlist. Antes, confirme que o arquivo pertence ao laboratório ou ao escopo autorizado.

fcrackzip -D -p wordlist.txt arquivo.zip

Registre versão do formato, tamanho do arquivo e resultado. Evite colocar senhas recuperadas no relatório público.

FIELD NOTE

03 / Coleta e análise de material

NetExec e pypykatz aparecem no índice original. Pypykatz foi deixado como marcador, sem procedimento. A separação útil é: coletar apenas material permitido no ambiente de teste, analisar localmente e remover os artefatos ao fim do trabalho.

Para enumeração de SMB, consulte SMB e Active Directory ↗.

FIELD NOTE

04 / Segredos de JWT

As notas citam o modo 16500 do Hashcat para checar segredos JWT fracos. Isso é diferente do caso alg: none, que é falha de validação de assinatura.

hashcat -a 0 -m 16500 TOKEN_DE_LAB wordlist.txt

Use chaves de alta entropia, algoritmos fixados pelo servidor e rotação adequada. A explicação de JWT está em Web Hacking ↗.

Hashcat

Quando você ja tem uma parte da senha e a sua hash, você pode usar o hashcat para descobrir o restante, basta seguir alguns passos

Para o exemplo iremos usar uma comparação de md5

# valores a serem usados
pass: UHI75GHI****
md5: 0feda17076d793c2ef2870d7427ad4ed

# comando para hashcat
hashcat -a 3 -m 0 0feda17076d793c2ef2870d7427ad4ed UHI75GHI?a?a?a?a
  • Criando uma wordlist
