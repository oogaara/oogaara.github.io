FIELD NOTE

01 / Redis

O rascunho mostra que configurações de diretório e nome de arquivo podem permitir escrita no sistema de arquivos quando o serviço está exposto e com permissões excessivas. O exemplo original tentava gravar um script PHP em uma pasta web; aqui o foco é verificar a configuração, sem implantar código.

redis-cli -h redis.lab.local CONFIG GET dir
redis-cli -h redis.lab.local CONFIG GET dbfilename

Defesa: restrinja acesso à rede, autentique o serviço, reduza permissões do processo e impeça escrita em diretórios servidos pela aplicação.

FIELD NOTE

02 / SMTP

Para enviar uma mensagem de teste em ambiente autorizado, as notas usam swaks. Troque endereços e host pelo laboratório e identifique o assunto para facilitar a auditoria.

swaks --to teste@lab.local --from auditoria@lab.local --server mail.lab.local --body "mensagem de teste" --header "Subject: teste autorizado"

Registre aceitação, rejeição, cabeçalhos e autenticação observada.

FIELD NOTE

03 / Impressoras: PS, PJL e PCL

As notas diferenciam PostScript (PS), Printer Job Language (PJL) e Printer Command Language (PCL). O quadro original reúne comandos de listagem, leitura e escrita de arquivos por linguagem.

Como guia, comece identificando o protocolo e o modelo, depois revise exposição de rede, autenticação, atualização de firmware e permissões de armazenamento. Nem todo comando do quadro se aplica a todo equipamento.

PS / linguagem de páginaPJL / controle de trabalhoPCL / descrição de impressão
FIELD NOTE

04 / Estabilização de shell

Depois de obter uma shell em um laboratório autorizado, uma PTY melhora edição, sinais e aplicações interativas. As notas trazem duas opções:

python3 -c 'import pty; pty.spawn("/bin/bash")'
# ou
script -q /dev/null -c bash

No terminal local, as etapas Ctrl+Z, stty raw -echo, fg e export TERM=xterm podem ajustar o modo interativo. A forma correta para dimensões é stty rows N cols N.

05 / Anotações para revisar

hping3: o rascunho usa carga ICMP de arquivo. Isso pode transportar conteúdo sensível; em um guia público, mantenha apenas a referência à ferramenta e à necessidade de autorização e controle de tráfego.

Bypass func: o link para dfunc-bypasser foi mantido como referência do rascunho. O ZIP não incluía um procedimento ou resultado validado.
